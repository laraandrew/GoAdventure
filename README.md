# GoAdventure

Expo mobile app for trip planning with weather-aware travel guidance.

## Status

This project is still a work in progress. The current app flow is centered on collecting trip inputs and returning weather-oriented results to help travelers plan better.

## Current scope

- Expo / React Native app
- splash, input, and results screens
- weather-focused travel planning flow
- iOS, Android, and web entry points through Expo

## Stack

- Expo
- React Native
- React Navigation
- TypeScript

## Local development

```bash
npm install
npm run start
```

You can also run:

```bash
npm run ios
npm run android
npm run web
```

## Roadmap direction

Short term, this repo should focus on making the existing planning flow cleaner and more reliable before adding broad new feature surface area.
